# Stage 5：联调、演示与交付代码验收

日期：2026-10-23。开发基线：9612a7a。第五阶段代码已实现；公开材料发布、物理设备与主观表演质量仍为独立待验事项。

## 交付代码

- “准备演示”原子恢复固定预设，先停止麦克风与本地媒体，不删除历史或取消云端任务。三轮快照一致，revision / 动作 token 正常递增。
- 演示步骤和预生成回放标记。历史视频只用于明确标识的回放；不冒充现场生成。
- doctor、PowerShell 启动脚本、verify、干净安装检查、release:info。Node 24 内置 SQLite；预检只检查凭证是否配置，不调用模型。
- 默认浏览器验收使用 3100 端口、独立临时 SQLite、空主密钥，避免使用个人记录或意外付费。真实服务脚本单独执行。
- 支持已安装 Chrome / Edge 的三轮演示与故障恢复测试，保留 Chromium 全量回归。
- 服务端 /api/metrics 只保留最近 128 条固定 operation / 毫秒 / 成败 / 时间，工具日志展示执行耗时；不收集 URL、任务 ID、台词、凭证或媒体。
- 新完成的 Take 保存 completedAt，并记录创建到首次观察完成的 avatar_total。历史记录不补造完成时间；传输请求计时在响应头返回时截止，不等同完整音频下载或首个可听声音。
- 本地原子 MP4 归档：上限 50 MB，校验 ftyp，边读边写临时文件并计算 SHA-256，成功后替换；失败保留旧文件。代理本地文件支持闭区间、开放区间和后缀 Range，非法区间返回 416。
- 归档元数据不改 TakeInput / inputHash；供应商过期后仍可回放已保存原视频。相同归档请求并发复用一次下载；归档不调用创建接口。
- 运行时数据目录 BOSON_DATA_DIR 默认 .data，构建不会将本地数据库或媒体追踪打包。未配置密钥时也能执行通用凭证模式检查，配置了密钥则额外检查精确值。

## 真实联调与 A23 耗时

缓存的合成指令通过实际采音 AudioWorklet、Boson Realtime 与工具执行，把预设的 45° 转为 90°，Wave 后回到 Idle。随后在两个真实浏览器中播放两个已保存 640×640 视频、Cut，并确认选择回放没有改变舞台，停止后麦克风 tracks ended。

本次短 TTS 的响应头约 845 ms，完整 7,052 字节约 847 ms；后续复验复用缓存。两个浏览器从连接按钮到成功工具结果的逐次耗时见摘要，包含建立连接与合成录音前导静音。样本量小，不计算或宣称 p95 / 生产可靠性。计时只保留当前进程最近 128 次观察；响应头成功不等于最终媒体质量通过。

本阶段没有新增 Avatar。第四阶段旧 Take 没有 completedAt，不能用复验查询耗时倒推生成总耗时；新任务的总耗时采集代码已经通过测试，真实新样本须下次显式生成时再记录。

## 联调发现并修复

供应商 anger 内容返回 404，fear 仍可下载，说明“任务 completed”不保证供应商永久保留视频。已增加本地归档，并从第四阶段已验证的同一原始文件恢复两个 Take；没有重新付费生成或更换视频内容。归档后的回放和 Range 由本地提供，供应商不可用时也可继续演示。

实际控制台发现缺少 favicon 的 404，已补项目自有 SVG 图标。图标与回放复验见最终摘要；Three.js / R3F 的 Clock 弃用提示属于依赖警告，不作为致命页面错误。
