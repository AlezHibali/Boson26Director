# Stage 1 实施与验收记录

日期：2026-10-23。环境：Windows PowerShell、Node.js 24.15.0、Next.js 16.4.3、Chromium 156（Playwright 1.64.1）。应用位于 Boson26Director 仓库。密钥由 .env.local 提供；报告不包含密钥或临时凭证。

## 实施结果

- 创建可运行的 Next.js / TypeScript / R3F 工程与 Capability Lab 页面。
- 实现服务端 Boson 临时凭证、TTS、Avatar 创建/查询/二进制下载适配器。
- 实现白名单情绪模板、输入限制、同源校验、401/403/429/5xx/超时错误映射和付费创建不自动重试。
- 两套原创 GLB 角色：每套 33 mesh、7 骨骼、2 morph、2 服装组、2 动画。能力来自实际模型检查；单元测试比较真实 morph 顶点并运行动画 mixer。
- 独立相机输出 640×640 正面截图，正确处理离屏渲染的 sRGB 色彩。外形或服装改变后，旧截图被标记为不同步。
- Realtime 使用浏览器短期凭证；AudioWorklet 输出 24 kHz、PCM16、单声道；支持停止播放、插话截断与麦克风释放。本阶段未接入导演工具。

## 联调中发现并修复的问题

1. Realtime 第一次 session.update 的确认事件是 session.created，后续才是 session.updated。首次实现只等 updated 导致探针超时；已同时处理两者，并用浏览器回归覆盖首次 created。
2. Next.js 开发服务器的内部 Request URL 可归一化到 localhost，与浏览器的 127.0.0.1 Origin 不同。改为使用请求 Host 验证实际同源，拒绝外站且不信任转发 Host。
3. 离屏截图原先未指定目标色彩空间，导致人像比舞台暗。已指定 sRGB 并重新捕获后用于真实 Avatar。
4. 浏览器测试的通用 alert 定位匹配到 Next 路由播报节点，改为定位应用告警；真实功能没有因此被误报通过。
